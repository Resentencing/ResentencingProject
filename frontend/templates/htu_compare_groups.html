Compare results across groups

In the Tool Hub, open the Compare groups tab. For ready-made public charts (no login), use the System Trends Viewer.

This tool builds charts from two categories you choose, such as county and action taken, or cohort and sentence type (ISL or DSL). You can filter by year, county, action taken, sentence type, or race before you update the chart.

Public charts first (no login)

The System Trends Viewer shows fixed charts for everyone, including:

  • Case progression — considered, letters sent, resentenced (where cases move through the system)
  • Letters by county
  • Years reduced by county
  • Cases by action taken
  • Race and ethnicity distributions

Open System Trends Viewer

Step 1: Compare and Split by

Compare — the main categories on the chart (rows or bars), such as County or Cohort. Each option shows how many cases are in that group.

Split by — the second category shown inside each bar (colors or segments), such as Action taken or Race. Compare and Split by must be two different fields.

{{ rad_section_end() }} {{ rad_section(flush=false) }}

Step 2: Filters (optional)

Narrow the chart with multi-select filters:

  • Filter: year
  • Filter: county
  • Filter: action taken (court outcome; replaces older labels like "event point")
  • Filter: sentence type (ISL or DSL; replaces older "offense" labels)
  • Filter: race
{{ rad_section_end() }} {{ rad_section(flush=false) }}

Step 3: Show and chart style

Show:

  • Number of cases — how many records are in each group
  • Total years reduced — sum of years taken off sentences (when available)

How many groups to show — limits how many categories appear (10, 14, 20, or 30).

Chart style — same data, different layout:

  • Stacked bars (horizontal) — totals with groups stacked in one bar
  • 100% stacked bars (horizontal) — proportions; each bar is 100%
  • Stacked columns or 100% stacked columns — vertical versions
  • Grouped columns — groups side by side for direct comparison

Click Update chart after you change settings.

{{ rad_section_end() }} {{ rad_section(flush=false) }}

Reading the chart

Bigger segments mean more cases (or more years reduced, if you chose that measure). Small groups can look dramatic in percentages; be careful citing tiny counties or cohorts in court or press.

Field definitions are on the variables page. In the chart, action taken means what the court decided; sentence type means ISL vs DSL.
