If nothing shows up

If you see no results, try:

  • using fewer words
  • checking spelling
  • searching by court case number or CDCR number instead of name
  • switching Search by to county or cohort

If the case should exist but is missing, check the Tool Hub Check tracking log tab or ask the team whether the letter is still being processed.
