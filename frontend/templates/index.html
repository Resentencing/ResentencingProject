More about this project

This website helps users understand how CDCR-initiated resentencing decisions are made by CDCR and the courts. This tool takes difficult-to-access public records, including PDF letters and Excel logs obtained through Public Records Act requests, and transforms them into a searchable, usable dataset. By organizing and coding this information, it makes it easier to understand how resentencing decisions are made and how cases move through the system.

What this website covers and what it does not

What this website covers

This website focuses on CDCR-initiated resentencing under Penal Code § 1172.1. These are cases where CDCR decided to review a sentence and send it back to court, often after a change in law, a possible sentencing error, or strong rehabilitation over time.

What this website does not cover

This website does not focus on prosecutor-initiated resentencing (AB 2942) or judge-initiated resentencing (AB 600). Each county handles those pathways differently.
