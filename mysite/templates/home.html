Welcome to the OCR WebApp

This web application simplifies converting PDF documents into searchable and editable formats using Optical Character Recognition (OCR) technology.

The application is built using Flask, leveraging libraries such as PyMuPDF and pytesseract for processing PDF files and performing OCR.
